## 四、未修项（如实披露）

| 编号 | 问题 | 原因 |
|------|------|------|
| U7 | FR-3.4 预览滚动同步（按源码行锚点映射） | 需给每个渲染块加 `data-src-line` 并监听 `cm-scroller`，工作量等于一个新模块；当前预览独立滚动，不影响可用性 |
| U8 | FR-1.8 悬浮球右键菜单 | 需主进程监听 `ball` 的 `context-menu`；托盘已有同功能入口，可降级接受 |
| U9 | 标签过滤点击无反应（`void tagFilter` 丢弃） | 需在 App 层按 tag 过滤 tree；当前为「点了没反应」，属功能缺失 |
| U12 | 切换笔记用 `setValue` 进入 undo 栈，Ctrl+Z 可能跨文件污染 | 需改用 `view.setState()` 或 `addToHistory.of(false)` |
| U13 | AI「中止(Esc)」只关面板不 cancel | 需 Esc 分支先 cancel |
| U14 | 顶栏无关闭按钮 | 失焦可收起，非阻塞 |
| U15 | 最近打开只写不读；首行标题改名未实现 | 属 FR-5.7/5.2 |
| E9 | 切目录不 flush、语义索引不随根切换 | 边界场景 |
| E12 | `crashingDraft` 崩溃草稿未实现（设置项存在但无效） | 需实现草稿机制或移除开关 |
| E13 | `did-fail-load` 未监听 | 产物缺失时的诊断能力 |
| P5 | `useCodeMirror` 每次 `docChanged` 全文 `toString()` | 大文档 GC 压力，未优化 |
| P6 | `docs` Map 与 MiniSearch `storeFields` 各存一份 body | 上万篇时内存翻倍 |
