完整版安装包 599 MB，GitHub Release 单文件上传在当前网络下不稳定，因此拆成 4 卷发布。

> 最后 59MB 反复失败，最终拆成 20MB 小块上传成功。合并顺序不影响结果，按名字排序 cat 即可。

## 下载后合并

六个文件下载到**同一个目录**，然后：

**Windows（CMD 或 PowerShell）**
```cmd
copy /b QuickNotes-Full-Setup-0.1.0-x64.exe.part-00 ^
      +QuickNotes-Full-Setup-0.1.0-x64.exe.part-01 ^
      +QuickNotes-Full-Setup-0.1.0-x64.exe.part-02 ^
      +QuickNotes-Full-Setup-0.1.0-x64.exe.part-03a ^
      +QuickNotes-Full-Setup-0.1.0-x64.exe.part-03b ^
      +QuickNotes-Full-Setup-0.1.0-x64.exe.part-03c ^
      QuickNotes-Full-Setup-0.1.0-x64.exe
```

**Git Bash / WSL / Linux / macOS**
```bash
cat QuickNotes-Full-Setup-0.1.0-x64.exe.part-* > QuickNotes-Full-Setup-0.1.0-x64.exe
```

合并后的文件名为 `QuickNotes-Full-Setup-0.1.0-x64.exe`，双击即可安装。
