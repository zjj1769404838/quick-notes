## 下载后合并

四个文件下载到**同一个目录**，然后：

**Windows（CMD 或 PowerShell）**
```cmd
copy /b QuickNotes-Full-Setup-0.1.0-x64.exe.part-00 ^
      +QuickNotes-Full-Setup-0.1.0-x64.exe.part-01 ^
      +QuickNotes-Full-Setup-0.1.0-x64.exe.part-02 ^
      +QuickNotes-Full-Setup-0.1.0-x64.exe.part-03 ^
      QuickNotes-Full-Setup-0.1.0-x64.exe
```

**Git Bash / WSL / Linux / macOS**
```bash
cat QuickNotes-Full-Setup-0.1.0-x64.exe.part-0* > QuickNotes-Full-Setup-0.1.0-x64.exe
```

合并后的文件名为 `QuickNotes-Full-Setup-0.1.0-x64.exe`，双击即可安装。
